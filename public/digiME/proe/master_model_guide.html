Master Modeling Techniques

The master model is a part file built entirely of curves, surfaces and construction geometry (i.e. planes, csys, points, etc.). Its purpose is to capture the following design goals.

  • Define and control product ID
  • Define and manage part break up
  • Communicate inter-part relationships and features
    • Reveal design
    • Screw boss locations
    • Component alignments
    • Snap location

Before one can start building a master model, one needs to know or understand the following.

  • Product ID
  • Part break up
    • Part line reveal location and design
    • External Draft Consideration
  • Internal comps that interface with the outer shell
  • Fastening schemes
    • Snaps
    • Bosses
  • CSYS placement

Use "Split" surfaces to define the reveal that separates the parts.

Build complex reveal joints in the master model.

  • Use enough detail to describe the inter-part relationship. Too much can clutter the master model.

 

 

Create surface geometry that represents the component in its simplest form and have enough definition to drive your design intent.

 

Geometry for internal components should be created if they reference more than one part.

  • Use just enough information to describe the interface.

 

More often than not, an interface requires some supporting construction geometry.

  • Use layers to hide construction geometry.
  • Build geometry in sections then place supporting features on a layer

 

Merging the master model into the respective parts should be accomplished using one of the following two methods.

    • Method 1: Master Model Merge (MMM)
      • This method merges or imports the entire master model into the dependent part.
    • Method 2: External Copy Geometry (ECG)
      • This method only imports predefined geometry and features into the dependent part.

(i.e. Only references for a power button get merged instead of the entire model.)

 

Method 1

    • You get EVERYTHING from the master model except datum planes if you choose so at the time of merging.
    • When you add features to the master model they automatically appear in your part when you regenerate.

Method 2

  • You create Publish Geometry (PG) features at the very end in your master model.
  • PG features define a collection of references.
  • The PG features in the master will be linked via the ECG feature in the part.

 

One can also directly select individual references from the master via the ECG however, this is not allowed. The references are too difficult and cumbersome to manage. When you add features to the master they can only be translated over to the part if they are added to the PG feature

After the master model references have been merged into your part via either method, start to form the part using the linked references.

    • Solidify a closed surface volume and cut away with split surfaces.
    • Or, create a closed surface volume with split surfaces or other surfaces and solidify.
    • Shell.

Assemble all merged parts using the same CSYS as used in the merge.

    • Use Regenerate > Automatic to regenerate all parts in the assy
