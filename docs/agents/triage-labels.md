# Triage labels

| Role              | Tracker label     | Meaning                                    |
| ----------------- | ----------------- | ------------------------------------------ |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation is required          |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter  |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required           |
| `wontfix`         | `wontfix`         | Will not be actioned                       |

When a published skill names a role, use the corresponding tracker label from
this table.
