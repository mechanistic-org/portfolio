# Project Onboarding Skill

## When to use this skill

- At the very beginning of a new session.
- When the user says "Onboard" or "Start session".

## Protocol

### 1. Lifecycle Awareness

- **Start:** You are reading this skill.
- **End:** The session ends with the **Conversation Miner**.
- **Golden Rule:** Persistent data bugs are likely Caching/Naming conflicts. Use "Snake Case Strategy".

### 2. Core Context Loading

You must scan these files to establish state:

1.  `src/content/docs/meta/AGENCY_MEMORY.md` (Active Context)
2.  `src/content/docs/project/GROK_LOG.md` (The Constitution)
3.  `src/content/docs/MAINTENANCE.md` (System Manual)
4.  `src/content/docs/ROADMAP.md` (Status)
5.  `src/content/docs/manifesto.md` (Philosophy)

### 3. Confirmation Protocol (Mandatory)

After reading the context, you must explicitly state:

> "I have loaded the Project Constitution. I acknowledge the Air Gap decree and will check for symlinks before assuming assets are missing.
> Erik Norris Portfolio Online. Ready for instructions."

- **Goal:** Reach the **"Singularity"** (Level 10 coolness).
