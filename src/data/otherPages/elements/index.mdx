## 1. Typography

The system uses a functional pairing of **Inter** (Sans-serif) for structure and **JetBrains Mono** (Monospace) for data.

### Headers (Inter)

# Heading 1
## Heading 2
### Heading 3
#### Heading 4

### Body (JetBrains Mono)

The quick brown fox jumps over the lazy dog. 0123456789.
All body text is treated as data. It should be legible, precise, and monospaced.

> **Note:** This is a blockquote. It uses the "Brutalist" style with a hard left border and no border radius.
