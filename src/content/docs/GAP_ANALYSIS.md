# Feature Parity Audit: Classic vs. Hyperspace

This document tracks the feature gaps between the V2 (Classic/DataSheet) and V4 (Hyperspace/NorrOS) themes.

## Feature Parity (Hyperspace vs Classic)

| Project       | Classic Status | Hyperspace Status | Gap          | Notes                                                             |
| :------------ | :------------- | :---------------- | :----------- | :---------------------------------------------------------------- |
| **D-Control** | 🟡 Partial     | 🟢 **Verified**   | **Resolved** | Enriched with "Project Buckley" War Stories (Adhesion, Faders).   |
| **D-Command** | 🔴 Missing     | 🟢 **Verified**   | **Resolved** | Enriched with "Project Danko" War Stories (Tinderbox, Umbilical). |
| **Swarm**     | 🟡 Glitchy     | 🟢 **Stable**     | **Resolved** | Interaction and Layout stabilized.                                |
