## Visual Taxonomy (New Components)

Use these components to break up the dense text and add visual rhythm to the case studies.

### 1. Zigzag Grid (Product Domain)
Best for showcasing 4 distinct view angles or features. Alternates Text/Image.

```astro
<ZigzagGrid
  items={[
    {
      title: "View 1",
      description: "Description of the first angle.",
      image: "https://placehold.co/800x600/101010/FFFFFF/png"
    },
    {
      title: "View 2",
      description: "Description of the second angle.",
      image: "https://placehold.co/800x600/101010/FFFFFF/png"
    },
    {
      title: "View 3",
      description: "Description of the third angle.",
      image: "https://placehold.co/800x600/101010/FFFFFF/png"
    },
    {
      title: "View 4",
      description: "Description of the fourth angle.",
      image: "https://placehold.co/800x600/101010/FFFFFF/png"
    }
  ]}
/>
```

### 3. Model Viewer (Interactive)
The standard viewer for GLB/GLTF assets.

```astro
<ModelViewer src="/assets/r2/project-name/model.glb" alt="Interactive 3D View" />
```
