# Personal User Manual: Erik Norris

> **Type:** Human/Machine Interface Protocol
> **Version:** 1.0

## 1. Operating Parameters
*   **Core Hours:** 0900 - 1800 PST
*   **Peak Flux:** 1000 - 1400 (Deep Work Block - Do Not Disturb)
*   **Comm Channels:** Slack (Async), Huddle (Sync/Critical), Email (Formal).

## 2. Communication Protocol
*   **Direct & Dense:** Prefer high-bandwidth, direct communication over polite padding.
*   **Context is King:** Provide the "Why" before the "What".
*   **Async First:** Default to written async updates unless immediate sync is required.

## 3. Feedback Loop
*   **Radical Candor:** I value blunt, constructive feedback.
*   **Response Time:** 24hr SLA for non-critical items.

## 4. Known Glitches
*   **Context Switching:** High penalty. Avoid scattering meetings.
*   **Scope Creep:** Will naturally expand scope to improve quality. Please constrain.
