A new 'Ticketing Hygiene' phase has been introduced into the `/session_close` ritual to address orphaned GitHub Issue objects. This mandates checking off the Definition of Done, leaving a summary comment, and explicitly closing the issue before moving it to 'Done' on the project board, ensuring a complete audit trail and accountability.
