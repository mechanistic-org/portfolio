Hooks can return structured JSON output to control system behavior, utilizing fields such as `systemMessage` to display UI messages, `continue` to block or stop execution, `stopReason` for blocking messages, and `hookSpecificOutput` for event-specific actions like injecting additional context or making permission decisions.
