The EN-OS memory architecture will explicitly define a dual-engine approach: ChromaDB will serve as the Vector Engine for fuzzy, semantic similarity matching, enabling agents to retrieve historical context like "thermal issues on Avegant." Obsidian will function as the Graph Engine, handling explicit, hard-linked relationships and hierarchy through its native markdown links and Dataview queries, eliminating the need for a separate graph database like Neo4j.
