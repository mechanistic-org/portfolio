A new sovereign infrastructure registry file, `r2_endpoints.md`, has been created to centralize documentation for all active Cloudflare R2 buckets. This registry provides a single source of truth, pairing each bucket's custom domain with its Cloudflare-provided `.r2.dev` URL, and explicitly notes the removal of the `assets-mo` bucket.
