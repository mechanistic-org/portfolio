Moltbook's rapid development led to a critical security flaw, exposing 1.5 million API keys and 35,000 emails from an unsecured Supabase database with public API keys. This "vibe-coding" approach, combined with autonomous agent access, became a canonical cautionary tale. It catalyzed a wave of security commentary and set a new, higher standard for agent platform security requirements, highlighting the risks of deploying agentic systems on unverified code.
