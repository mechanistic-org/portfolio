# Historical design language guide

**Superseded.** This route previously held an early design proposal with Inter
headings, JetBrains Mono narrative text and broad styling rules. Those prescriptions
are not the current design system and must not be applied to new work.

Use the [current rendered design reference](/design-system/) and the repository's
[DESIGN.md](https://github.com/mechanistic-org/portfolio/blob/main/DESIGN.md).
The current portfolio uses Barlow body text, Barlow Condensed headings and Share Tech
Mono labels, with the runtime sources named by that reference. Related-site layouts
retain the differences appropriate to their content.

The old proposal is preserved in [the preceding version](https://github.com/mechanistic-org/portfolio/blob/e0367b739049e957bcbeed261f767af13a02ba4b/src/content/docs/design/style_guide.md)
and Git history. It is useful provenance for the design's evolution, not a competing
set of current instructions. No personality or voice prescription transfers from it.

For the implemented choices and their limitations, start with the
[colophon](/colophon/) and inspect the actual components and page specimens.
