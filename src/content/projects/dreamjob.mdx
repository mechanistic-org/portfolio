## Meta-Engineering: The Plasticity Pipeline
> **Process:** `Plasticity (Geo)` -> `Blender (UV)` -> `Substance (Paint)`

This portfolio project itself is a "HardTech Product." The assets displayed here were not merely "designed"—they were engineered using a CAD-based workflow to ensure 100% manufacturing feasibility of the visual language.

### 1. Geometry Qualification (Plasticity)
*   **Input:** Conceptual constraints (e.g., "Career Goal").
*   **Process:** Parasolid kernel modeling. No sub-d modeling.
*   **Output:** High-fidelity B-Rep surfaces.

### 2. The Conversion Bridge (Blender)
*   **Action:** Automated UV Unwrapping via the `plasticity-blender-bridge`.
*   **Metric:** 98% UV efficiency (minimal wasted texture space).
*   **Topology:** Quad-dominant mesh optimized for WebGL transmission (`.glb`).

### 3. Surface Reality (Substance Painter)
*   **Material:** "Titanium Ceramic" (White) and "Matte Forged Carbon" (Black).
*   **Technique:** Procedural edge wear driven by curvature maps baked from high-poly CAD data.
*   **Impact:** Zero-latency photorealism in the browser.
