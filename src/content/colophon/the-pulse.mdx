## Source: the record

The site renders from a record, not from memory. The record is a Markdown vault of
{fmt(stats.record.vault_md_files)} files, {fmt(stats.record.canon_md_files)} of them canon
extracts under a published schema, curated into {stats.record.canon_project_entities} project
entities carrying {fmt(stats.record.canon_entity_words)} words of canonical truth. The operator
registry adds {fmt(stats.record.registry_docs)} documents and {fmt(stats.record.registry_words)}
words of decisions, session logs, and mined findings. Assets live in an object store:
{fmt(stats.record.r2_assets)} files, about {stats.record.r2_assets_gb} GB.

## Process: the machine

The pipeline is {stats.engine.python_scripts} Python scripts, {stats.engine.test_files} of them
tests, organized behind {stats.engine.skills} skills, {stats.engine.scheduled_tasks} scheduled
tasks, two supervised services, {stats.engine.mcp_servers_active} MCP servers, and
{stats.engine.session_hooks} session hooks. The point of the inventory is not size. It is that
every piece is versioned, and the whole machine can be rebuilt from the repository.

The stack commits its own work. Of the {fmt(stats.engine.commits_last_30_days)} commits on the
core repo in the last thirty days, most were landed by an hourly task that drains the
session-mining queue: {fmt(stats.flow.mine_drain_runs)} completed runs so far, and
{fmt(stats.record.mined_notes)} mined notes now sitting in the registry. Nobody remembers to
persist a decision. The scheduler does.

Ada, instead of being shipped to a cloud model.

## How these numbers are made

- Every figure came from a command, not a recollection: git for commits and line counts, the
  GitHub API for issue flow, the Windows scheduler for tasks, the drain log for mining runs, the
  transcript archive for tokens. A second, independent pass re-derived each headline number
  before this page shipped.
- Commit counts include the machine's own commits. That is disclosed because it is the design,
  not an inflation.
- Token totals cover the primary agent surface only. Other surfaces would add to the total, not
  subtract from it.
- This is a dated snapshot ({stats.as_of}). The corpus moves daily; the page states its date
  instead of pretending to be live.

The machine that produces these numbers is documented in [EN-OS](/colophon/en-os), and the
pipeline that renders this page from the record is the same one being measured.
