## The Problem of Paper

> **Context:** Thirty years of shipped hardware leaves a paper trail no résumé can hold: engineering change orders, data control drawings, faxed tooling markups, thermal-chamber logs, first-article inspection reports, vendor ultimatums, war-room minutes.

The evidence existed. It sat in boxes, drives, and a 23-megabyte text file. A career's worth of provenance — and no system of record.

This site is the system of record. EN-OS is the machine that builds it.

## The Operating System

EN-OS is a local agentic stack — a personal operating system for forensic memory. The pipeline runs in one direction:

1. **The Archive.** Raw evidence — scans, CAD, email corpora, test logs — curated into a staged asset vault.
2. **The Interrogation.** Project archives loaded into NotebookLM notebooks (174 and counting) and forensically interrogated: _what failed, what was done, what did it yield._
3. **The Registry.** Extracted intelligence lands in a versioned forensic registry — synced summaries, mined session artifacts, a semantic database behind an MCP router.
4. **The Hydration.** Scripts write the intelligence into Zod-validated frontmatter. Schema, not vibes: every claim a field, every field typed.
5. **The Site.** Astro compiles the registry into static pages — plus machine-readable surfaces (`llms.txt`, `/api/projects.json`, `resume.json`) so the next reader doesn't have to be human.

## Four Generations of Memory

The memory layer was not designed; it evolved, leaving fossils:

| Generation | Mechanism | Fate |
| :--- | :--- | :--- |
| 1 | **The Monolith** — one 23 MB master-context file | Retired. Reading it whole could kill an agent's entire session. |
| 2 | **Agency Sync** — IDE knowledge folders mirrored into the repo | Demoted to a secondary read surface. |
| 3 | **Sidecars** — per-project `_intelligence` and `_entropy` files | Valid architecture, sparsely deployed. |
| 4 | **The Semantic Registry** — ChromaDB behind an MCP router | Current canon. Memory you can query instead of swallow. |

## The Crew

The system runs a staffed newsroom of non-humans: cascade swarms that pass a draft through five voices (narrative designer through chief storyteller) before it ships; an eight-persona deep-tech panel for harder targets; session miners that convert every working transcript into registry artifacts; watchdogs that redeploy the router when its source drifts.

## The Dump Incident

Honesty clause: the machine misfired, publicly.

- **Trigger:** The interrogation transcripts themselves — mining prompts, system-prompt blocks, dangling "Tell me more about…" suggestions — leaked onto live project pages as body text. Visitors could read the puppet strings. At peak, seventeen of twenty-two flagship-tier pages carried raw chat dump.
- **Intervention:** A written contract — the Perfect Deep Dive Page Contract — defining what a finished page owes its reader: one authored narrative in trigger/intervention/result grammar, a visible source trail naming the evidence, schema-complete frontmatter, zero unresolved citations. Then a normalization campaign against it.
- **Result:** One batch alone removed 2,683 lines of transcript and replaced them with 329 lines of authored forensics. The contract is now the gate every page passes before it counts.

<Admonition variant="tip">
	The failure mode and its correction are both in the git history. A forensic
	archive that hid its own defects would be a contradiction in terms.
</Admonition>

## The Point

This is not a website with AI features. It is the same discipline that shipped the hardware, pointed at the career itself: a DCD protocol for memory. Define the interface, validate against it, reject drift, keep the source trail.

Structure the chaos. Index the decisions. Ship the hardware.
